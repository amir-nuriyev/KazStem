# Security policy

Please do not disclose a security-sensitive issue in a public GitHub issue.
Use GitHub's private security-advisory reporting for this repository instead.

Only the latest tagged release receives security fixes. Runtime provenance
verifies the bundled Kazakh resources and the extracted HFST/CG toolchain, but
the host operating-system libraries are explicitly outside that byte-closed
boundary. See `README.md` and `docs/CONTRACT.md` before relying on an
`official=true` report as a broader supply-chain statement.
